## Build

```bash
# JDK 17 + Android SDK 35 required.
gradle assembleDebug
gradle installDebug

# Release (reads ../keystore.properties — copy keystore.properties.example)
gradle bundleRelease
```

`gradle/wrapper/gradle-wrapper.properties` is committed; the wrapper JAR is generated by Studio or
`gradle wrapper` and is intentionally not in the repo.

## Design decisions worth knowing

**One occurrence function.** `Schedule.occursOn` decides whether a vow is due on a date. Calendar
cells, the streak, the analytics and the alarm all call it — a reminder cannot fire for a day the
calendar says is empty.

**A real pañcāṅga, not an approximation.** `Astronomy.kt` evaluates the 60-term lunar longitude and
latitude series and the Meeus solar series on every launch; `Panchang.kt` takes the tithi
prevailing at sunrise and solves the exact instant it ends. Results are memoised per
(date, place) and the cache is dropped when the place changes. `Panchang.place` is updated from
`SettingsStore` in `SadhanaApp`, so every screen and the alarm scheduler read the same place.

**No seed data.** `SeedData` and its `seeded_v1` flag are gone. A new install opens on the
three-step welcome (name → place → begin), followed by a genuinely empty Today screen.

**Alarms, not polling.** `setExactAndAllowWhileIdle` per upcoming occurrence, re-armed after
firing, reboot, package replace and timezone change. If `SCHEDULE_EXACT_ALARM` is not granted —
or the OEM refuses — it falls back to `setAndAllowWhileIdle` instead of crashing. The armed
`(sankalp, date)` pair is recorded in SharedPreferences so cancellation is exact.

**Graceful AI.** `OnDeviceAi.capability()` inspects AICore presence, API level, total RAM and
`isLowRamDevice`. Tier 3 (local statistics) is a first-class surface, not an error state — the
insights, heatmap and reflection all still render.

**Snapshot-free history.** Marks are `(sankalpId, date)` rows that survive pausing, stopping and
deleting a vow's schedule. The app never rewrites the past to make a chart look better.

## Play Store notes

- No `INTERNET` permission, no analytics SDK, `usesCleartextTraffic=false`.
- `USE_EXACT_ALARM` is intentionally absent (Play restricts it to alarm/calendar apps);
  `SCHEDULE_EXACT_ALARM` is requested and degrades gracefully.
- R8 + resource shrinking, release signing from `keystore.properties`, adaptive + monochrome
  launcher icon, day/night splash and window backgrounds, predictive back enabled.
